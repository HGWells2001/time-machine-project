## Norme di pubblicazione

1. **GitHub:** Markdown, tabelle CSV, issue e cronologia delle revisioni; **nessun `.obj`**. Aggiungere link prima di duplicare file pesanti.
2. **Google Drive:** conservare PDF, DXF, CAD, immagini e archivi ZIP originali, anche se contengono OBJ. La condivisione **non** viene modificata automaticamente.
3. **Diritti:** la tavola Perrotta/Coleman e le immagini/fonti terze vanno citate con il relativo URL; non ridistribuirle pubblicamente senza permesso.
4. **Sicurezza:** le quote OBJ sono dati geometrici preliminari. Fino a validazione e approvazione tecnica, nessun DXF va trattato come esecutivo per taglio CNC.
5. **Nuove revisioni:** assegnare ID risorsa, data, versione, stato, link Drive e, quando utile, un elenco dei file interni; aggiornare anche [REVISIONI](REVISIONI.md) e [AVANZAMENTO](AVANZAMENTO.md).
