## Provenienza e sicurezza della documentazione

- **D** = misura dichiarata esplicitamente da una fonte verificata, sempre riferita all'oggetto/versione indicata.
- **G** = quota ricavata dalla geometria di un file o da una scala grafica.
- **I** = ipotesi progettuale; **V** = informazione da verificare.
- Il diametro **60″** attribuito a una precedente realizzazione Coleman compare nei dossier storici di questo progetto, ma **non è stato ancora ricondotto con sufficiente certezza alla configurazione MGM del 1960**. Resta un punto aperto in [issue #1](https://github.com/HGWells2001/time-machine-project/issues/1).
- S01 e le fotografie esterne sono di terzi. Questa repository contiene collegamenti e sintesi originali, non scansioni o foto ripubblicate.
- I file Drive non sono stati resi pubblici: il collegamento in un repository pubblico **non dà automaticamente accesso** senza i permessi del proprietario.
